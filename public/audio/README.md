# IESE Audio Files Directory

You can place your real audio recordings here in this folder:
- `l1-ex1.mp3` -> Level 1 Exercise 1 (Phone dialogue - Tim and Bill)
- `l1-ex2.mp3` -> Level 1 Exercise 2 (Weekend leisure activities)
- `l1-ex3.mp3` -> Level 1 Exercise 3 (Soccer game Kansas City vs Dallas)

Alternatively, you can click "Cargar Archivo de Audio" directly in the application UI, which will store the file in your browser's IndexedDB storage and play it immediately.
